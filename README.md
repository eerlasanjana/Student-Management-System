# 🎓 Student Management System

A Python-based Student Management System that performs CRUD (Create, Read, Update, Delete) operations with permanent JSON storage.

## ✨ Features

- ➕ Add Student
- 📋 View Student Details
- 🔍 Search Student
- ✏️ Update Student Information
- ❌ Delete Student
- ✅ Duplicate Student ID Validation
- ✅ Input Validation
- 💾 Permanent Data Storage using JSON

## 🛠️ Technologies Used

- Python
- JSON
- File Handling

## 📁 Project Structure

Student-Management-System/

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd Student-Management-System
```

3. Run the program

```bash
python student_management.py
```
